# 量化回测方法论核心框架

## 回测七宗罪
1. **过拟合**: 参数越少越好，必须样本外验证，Walk-forward
2. **数据窥探**: T日信号T+1执行，不能用当日收盘做当日决策
3. **生存者偏差**: 股票池含退市股（我们的5207只已包含）
4. **交易成本**: A股单次换手≥0.2%（佣金+印花税+滑点）
5. **选择性报告**: 不挑好的参数组合说
6. **微观结构**: 涨跌停/停牌/集合竞价处理
7. **数据质量**: 明确复权方式，停牌股排除

## 信号评估指标
- IC (信息系数): 信号与收益相关性，|IC|>0.03为有效
- IC_IR: IC均值/标准差，>0.5为好信号
- 分组单调性: 按信号分5-10组，收益应单调递减
- 多空收益: Top组-Bottom组年化>5%
- 信号衰减: 检验T+1到T+10预测持续性

## GoAI已验证信号
- 连续下跌反弹: 准确率72.7%
- 大跌后反弹: 有效
- 冰点反转: 有效
- 多信号叠加≥6: 准确率90.9%
- 连板高度(≤3或连续下降): 唯一方向正确的退潮信号（但样本小13-33天，未确认显著）

## GoAI已证伪
- 逐日方向预测: 本质噪声(v4.0确认)
- 单信号低置信: 需叠加
- 全市场情绪阈值法(涨停/跌停/涨跌比/均幅): v1+v2两轮独立验证，Z-score均<0，精确率低于随机baseline
- 全市场情绪趋势法(MA5斜率/连续下降): v2验证，同样无预测力(Z=-1.08)
- **结论：涨停/跌停/涨跌比/均幅/连板高度作为全市场单日信号，不具备预测未来2-5日退潮的能力。这组指标是市场同步指标，不是前瞻指标。**

## A股核心认知
- "跌了会弹，涨了不一定跌" → 做多反弹是核心alpha
- 信号驱动 > 逐日预测
- 不是预测明天涨跌，是高置信时下注

## 回测设计Checklist
```
□ 含退市股？（生存者偏差）
□ 无未来数据？（数据窥探）
□ 有样本外区间？（过拟合）
□ 成本≥0.2%？（交易成本）
□ 涨跌停处理？（微观结构）
□ 参数<5个？（过拟合）
□ 多时段有效？（鲁棒性）
□ 分组单调？（信号质量）
```

## 推荐路线（不需要多因子量化）
1. 信号驱动策略（当前路线）
2. 板块轮动（四维因子+龙头+情绪）
3. 事件驱动（财报+政策+断板）

## 准确率评估警戒线
**如果你的预测系统准确率低于50%，不要认为'反转后就是有效信号'。**
当准确率显著低于50%时，通常不是算法有反向预测能力，而是算法存在**系统性缺陷**：
- 双向误差（涨→错 + 跌→错）→ 信号没有预测能力
- 单向误差（全看涨错→可反转）→ 但有偏见的信号通常也弱
- 回填算法的40.8%属于双向误差，不是可逆信号
- 正确做法：检查误差模式，改进算法而非反转

详见 `trading/daily-report-gen` 的 references/accuracy-evaluation.md 文档。
