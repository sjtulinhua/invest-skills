# 情绪周期统一交易框架

## 总纲

**市场由情绪驱动。赚钱效应吸引资金涌入，亏钱效应驱离资金离场。跟着情绪走，不要自以为是。**（涅槃重升）

7位游资大牛的核心共识：
1. 投机的本质是**赚钱效应的延续**，对资金的吸引
2. 情绪有周期，周而复始：低迷→启动→高潮→退潮
3. 交易要跟着情绪走，仓位随情绪调整
4. 系统化思维优于碎片化知识——要有树干（核心思想），树枝（小规律）可以不断进化

## 一、六大情绪维度（分析框架主干）

源自涅槃重升。市场由六个情绪维度构成，要结合分析，不同行情侧重不同：

| 维度 | 观察指标 | 强化信号 |
|------|---------|---------|
| **投机情绪** | 涨停数、连板数、连板高度、炸板率 | 连板高度提升、炸板率下降 |
| **市场情绪** | 指数强度、涨跌比 | 指数突破阳线大幅强化 |
| **板块情绪** | 板块涨幅、资金偏好、有高度/有主升/有人气 | 干柴烈火，容易集体爆发 |
| **整体市场情绪** | 综合赚钱效应、论坛氛围、消息面 | 突破阳线大幅强化 |
| **整体投机情绪** | 近期投机氛围、高位妖股、涨停溢价 | 高位妖股涌现、涨停溢价走高 |
| **整体板块情绪** | 龙头拉开空间、人气始终活跃 | 非一日游题材、持续活跃 |

**侧重要领（涅槃重升）：**
- 整体投机情绪强 → 做低位超强前排、高板块情绪点、换手核心
- 情绪不差 → 主动进攻点给仓位
- 整体板块情绪强 → 龙头板给仓位
- 情绪条件好 → 预判成分多，走强点就上；分歧大 → 低风险走强点
- 整体投机强但板块不强 → 资金轮动
- 整体板块极强（如雄安） → 等板块情绪走强即可
- 整体投机极强 → 不停做低位前排+高板块情绪点

## 二、情绪周期四阶段（定位+操作）

源自92科比，融合其他人补充：

### 阶段一：低位震荡（试错期）

**特征：** 接在主跌之后，市场迷茫，涨停少、连板断档
**操作：**
- 92科比：**高低切模式**——龙头见顶杀高位时，是最好的布局低位新题材的时机。低位2板切入，勇气+题材预判
- 养家：敢于大盘低位空仓，不要为了交易而交易
- 独股一箭：利用上升惯性，关注强势股首次启动

**仓位：** ≤30%，试错为主

### 阶段二：主升（赚钱期）

**特征：** 涨停潮、连板高度攀升、成交放大、板块持续性出现
**操作：**
- 92科比：**做龙头**——看好题材故事，分歧时大胆介入，不在乎打板还是低吸
- 作手新一：围着主线和龙头做，追涨必须选主线
- 养家：利用大资金优势，敢于强势股加仓

**仓位：** 50-100%，重仓出击确定性

### 阶段三：高位震荡（分歧期）

**特征：** 炸板率飙升、高位股崩塌、板块内部分化
**操作：**
- 92科比：**轻仓应对**，不建议博弈二波穿越（性价比低）
- 涅槃重升：关注情绪股和指数关系——情绪涨多了可能走弱，配合指数下行就大跌
- 作手新一：趋势向下不参与小行情，屏蔽杂毛

**仓位：** ≤30%，防守为主

### 阶段四：主跌（恐慌期）

**特征：** 跌停多于涨停、亏钱效应扩散、成交萎缩
**操作：**
- 92科比：**第一天杀跌很恐怖，第二天继续杀→尾盘找买点，第三天必有情绪修复**
- 养家：冰点之后是反转，敢于逆势买入恐慌盘
- 独股一箭：关注核心标的的二波机会
- 龙飞虎：防守优于进攻，活着比赚钱重要

**仓位：** 0-20%（冰点反转信号出现时可加仓）

## 三、选股三线策略（龙头/补涨/切换）

源自92科比，这是短线操作的核心思路：

### 龙头线
- 龙头是最先涨停、辨识度最高、带动板块的个股
- 主升阶段重点做龙头，分歧买入
- 作手新一：逻辑内核是最强源动力，选龙头看逻辑
- 涅槃重升：个股的市场地位最重要

### 补涨线
- 龙头不停涨，低位同题材人气品种干柴烈火
- **补涨心理逻辑（92科比）：**
  1. 踏空比套牢还难受 → 眼红效应
  2. 龙头把逻辑演绎透了 → 补涨减少分歧直接一致 → 模仿加速
  3. 做龙头的资金赚钱了 → 赚钱效应溢出到同题材
  4. 亏钱效应未扩散 → 场外资金仍在
- 孤独牛背：龙头打不到 → 做快速补涨龙头（同板块接力）

### 切换线
- 老题材退潮，新题材试错
- 低位震荡期重点做高低切
- 题材预判能力是关键（92科比）：先于市场发现可发酵的事件

## 四、操作手法按场景（消除矛盾）

**核心原则：手法服务于场景，不服务于信仰。**

| 手法 | 适用场景 | 理论来源 |
|------|---------|---------|
| **打板** | 主升期、确定性要求高、情绪强 | 92科比、作手新一、涅槃重升 |
| **低吸** | 主跌尾盘、核心标调整20-30%后、情绪修复前 | 独股一箭、92科比、乔帮主 |
| **追涨/半路** | 分歧转一致时、题材逻辑清晰、走强点确认 | 涅槃重升、作手新一 |
| **排板（一字三板）** | 连续一字龙头的第三板分歧点 | 作手新一独创 |
| **潜伏** | 高低位切换期、预判新题材发酵前 | 92科比、龙飞虎 |

涅槃重升："为什么一定要打板？确定性。好行情不打板太容易错失，烂行情不打板太容易犯错。"
独股一箭："短线成功的秘诀：总盈利次数>总亏损次数，平均每次盈利点位>亏损点位。关键是利用强势股的上升惯性。"
92科比："真正的悟道不是限制于某种手法。手法是初级阶段。"

**结论：主升打板为主，退潮低吸为主，始终以确定性和盈亏比为决策依据。**

## 五、仓位管理矩阵

### 龙飞虎动态仓位法
- 核心原则：**防守优于进攻，活着比赚钱重要**
- 强势市场：重仓出击，以攻代守
- 震荡市场：半仓操作，快进快出
- 弱势市场：轻仓试错，不亏就是赚
- 主跌市场：空仓观望，等冰点反转

### 养家仓位哲学
- 敢于大盘低位空仓（别人恐惧时更恐惧）
- 敢于大盘高位满仓（赚钱效应最强时重仓）
- 反直觉：低位不代表安全，高位不代表危险——**看的是情绪，不是点位**

### 仓位速查表

| 周期阶段 | 建议仓位 | 核心策略 |
|---------|---------|---------|
| 低位震荡 | 10-30% | 试错新题材，高低切 |
| 主升 | 60-100% | 重仓龙头，打板/追涨 |
| 高位震荡 | 10-30% | 轻仓或空仓，防守 |
| 主跌 | 0-20% | 空仓等冰点，或尾盘试探 |

## 六、赚钱/亏钱效应判断清单

### 赚钱效应信号（zarili+养家+独股一箭）
- ✅ 涨停家数持续增加
- ✅ 连板高度不断拓展
- ✅ 炸板率持续下降
- ✅ 涨停次日有溢价（涨停板赚钱效应）
- ✅ 北向资金持续流入
- ✅ 板块持续性出现（非一日游）
- ✅ 论坛/社交媒体情绪亢奋
- ✅ 成交额环比放大

### 亏钱效应信号
- ❌ 跌停家数超过涨停
- ❌ 连板断层（高度骤降）
- ❌ 炸板率>40%
- ❌ 涨停次日低开（涨停板亏钱效应）
- ❌ 北向资金持续流出
- ❌ 板块轮动加速（今日涨明日跌）
- ❌ 成交额持续萎缩

### zarili效应循环
```
赚钱效应 → 吸引资金 → 推升股价 → 亢奋 → 泡沫
                                    ↓
亏钱效应 ← 驱离资金 ← 股价下跌 ← 恐慌 ← 破灭
```
**核心：赚钱效应的延续 = 资金的持续流入。一旦资金停止流入，效应逆转。**

## 七、风险规避清单

### 涅槃重升：最容易亏钱的6种情形
1. **最有赚钱效应板块的对立面** — 逆着主线做
2. **末期机会** — 收益大但做错代价也大，必须追求确定性
3. **非主流冷门** — 自认为低风险而重仓，情绪转差时亏损巨大
4. **系统性风险** — 全市场杀跌
5. **补跌** — 前期强势股补跌
6. **逆情绪抓小转折** — 市场情绪差时抓小转折，根本不能逆情绪

### 92科比忠告
- "迷于表象，死于本质" — 看透投机本质
- "大部分人亏损不在于普跌，而是不断参与小反抽遭遇大面" — 没有大主流板块时不操作
- "故事是否有更多人来接盘" — 买入前想清楚谁来接力

### 作手新一纪律
- "短线乱打是回归赤贫的捷径" — 管不住手买杂毛，真机会来了没子弹
- "行情不好很少超过1/10仓位"
- "不在主线的追涨都是自己找难受"

## 八、系统化思维（涅槃重升）

**树干树枝理论：**
- 树干 = 核心交易思想（情绪周期+赚钱效应）
- 树枝 = 具体战法和规律（打板、低吸、补涨、切换）
- 没有树干，知识是散沙，行情一变就散
- 不断进化：新发现可以长出新树枝，好的树枝可以升级为树干

**核心忠告：**
- "人与人最大的差距不在智商，而是思维模式"
- "先不要学新知识，一定要建立自己的系统"
- "每笔操作、每步思考，是否是为了训练而存在"

## 九、Agent使用指南

### 输入数据
- 涨跌停数量和明细
- 连板高度和数量
- 炸板率
- 成交额（环比变化）
- 北向资金流向
- 板块涨幅排名
- 情绪股表现

### 输出判断
1. **六大情绪维度评分**（每项强/中/弱）
2. **周期阶段定位**（低位震荡/主升/高位震荡/主跌）
3. **赚钱/亏钱效应判定**（方向+强度）
4. **仓位建议**（具体百分比+理由）
5. **选股方向**（龙头/补涨/切换？哪个题材？）
6. **操作手法建议**（打板/低吸/追涨/观望）
7. **风险提示**（当前最大的坑是什么）
