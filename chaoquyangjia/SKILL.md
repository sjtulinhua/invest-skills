# 炒股养家 交易认知框架

> 蒸馏自养家心法1-15期 + 炒股养家干货合集62页（约7万字）。炒股养家（淘股吧ID: 炒股养家，席位：华鑫证券上海茅台路/淞滨路），A股情绪流派开山鼻祖。90年代末入市，经历从短线→价值投资→回归短线的十年迷茫，2008年职业投资初期从90多万亏到40万，2010年悟道后资金曲线平滑上升：5月200万→9月300万→11月400万→2011年1月600万，终成一方游资。

## 一、核心心智模型（6个）

### 1. 情绪理论总纲

**底层逻辑：** 养家心法的核心是基于对市场情绪的揣摩，进而判断风险和收益的比较。影响人的情绪有很多方面——政策消息刺激、外围股市涨跌——但归根到底都会转换为**赚钱效应的多寡**。所以分析市场情绪就是看赚钱效应。

**操作循环：**
1. **研究市场情绪** — 通过情绪分析与推演（现在叫情绪流/周期流派）
2. **分析赚钱效应** — 度量当前赚钱/亏钱效应的现状
3. **推演情绪走向** — 通过指标变化推演未来情绪方向
4. **衡量风报比** — 根据情绪预判，对目标方向进行风险与收益比较
5. **指导操作与仓位** — 根据风报比决定出击力度

**关键认知：** "分析本身是建立在已有市场上的，但预判是预测性质的，没人能永远保证都对，只能一直走在努力的趋近于高胜率的路上"

### 2. 赚钱效应/亏钱效应模型

**赚钱效应：** 场内赚钱的人多了、赚大肉了，人性就会贪婪忘我。这说明场内赚钱效应好/非常好，大部分核心标都在加速。赚钱效应非常强烈时，很难突然反转——因为人赚了钱就会继续做，期望赚更多。

**亏钱效应：** 上面的反面。亏钱效应爆棚时，群体恐慌，应该更恐慌——空仓等待。

**核心规则：**
- **有赚钱效应 → 做热点为主**：核心方向锁仓，非核心向核心置换
- **有恐慌效应 → 做超跌为主**：大盘超跌时买超跌的股票，大部分第二天冲高就走
- **别人贪婪时我更贪婪，别人恐慌时我更恐慌** — 养家版巴菲特名言的反转
- **情绪向上阶段，别人恐慌我贪婪；情绪向下阶段，别人贪婪我恐慌** — 万狮虎补充

**超跌出击条件：**
- 大盘角度：连续下跌一段后，再出现大阴线，指数远离5日线
- 板块角度：超跌板块在连续下跌后，再次出现集体性大幅杀跌
- 两者结合 = 超跌出击时刻

**反向操作机会：**
- 情绪周期刚向上，外围大跌导致低开恐慌 → 大胆推进仓位
- 情绪从上转向下，外围暴涨导致高开 → 反而是离场机会
- 外围通常只影响开盘，部分情况下可以利用做反向操作

### 3. 龙头属性模型

**养家对龙头的理解：**
- "我们这个市场，有大量的短线客，做短线的想的都是要做龙头，只要被市场确定为龙头，卖给谁就不再是问题，相反问题变成要买的人很多，筹码有限，所以就造成连续涨停的结果"
- 高手买入龙头，超级高手卖出龙头

**龙头四个属性（万狮虎总结养家思想）：**
1. **对盘面的直观带动性** — 情绪向上时主动引领，情绪向下时对抗抛压
2. **对场内赚钱效应的向上带动** — 带不起场内赚钱效应的都是伪龙头，高度一般不会太高
3. **PK能力** — 低位时同身位、同板块竞争，得赢。输了的不是这波行情的龙头
4. **大众情人最佳** — 低吸、打板、半路都可以随时上车。推一字的过程中不算龙头，必须先开板承接分歧后看走势才可能定性

**龙头与超跌的关系：**
- 超跌品种稳住了 → 强势个股机会就大
- 超跌品种继续创新低 → 强势个股补跌在即

### 4. 仓位管理模型

**核心理念：** 仓位让自己觉得舒服就可以。有好机会就重点搞，没有好机会就拿着钱耐心等待或者轻仓练盘感。

**分阶段策略：**
- **强势阶段** — 做最牛个股的主升浪，可以多拿几天
- **弱势阶段** — 做超跌反弹为主，大部分第二天冲高就走，亏钱也走
- **平衡格局** — 部分持有热点板块观察变盘方向，试错+加仓+向上买

**资金曲线目标：** 稳步向上，小阴小阳为主，偶尔确定性高时大阳出击。避免大回撤。

**试错系统：**
- 操作含很多试错单，结果大多小赢小亏
- 试错的目的是感受市场情绪，判断何时该出重拳
- "好比拳击时很多刺拳是为了试探对手，有没有打中不重要，重要的是借试探判断何时出重拳"

### 5. 预判/跟随/确认模型

**操作节奏：** 预判 → 试错 → 确认 → 加仓

**卖出节奏：** 预判减仓 → 确认卖出

**核心原则：**
- 买入机会，卖出不确定（卖出风险）
- 不止损不止盈 — 不看好了就卖出，管它是不是止损。"3%止损过于教条"
- 亏损不是走的理由 — 走势低于预期，即使盈利也要离场；走势符合/超预期则持有
- 介入前要有合理预期 — 这个预期需要通过回溯过去类似情况来形成

**动态判断：**
- 预期是动态变化的，要结合大盘和整个市场状况
- "做的是短线，但是看的是更大的局"
- 盘中动态判断：以赚钱效应为指引，盘中即可作出判断及时介入

### 6. 热点/主线模型

**热点分类：**
- **长期的主流** — 能持续，可以反复做（如新兴产业是跨年度主线）
- **短期的支流** — 爆发力强，也有可操作性

**热点介入方式：**
- 提前预判埋伏
- 盘中追击
- 随机应变为主

**核心认知：**
- "不管大盘怎么跌，未来能起来的品种还是在这个圈子里面" — 主线穿越牛熊
- 热点强度判断：如果新热点强度较高，放弃超跌模式，直接攻击性热点操作
- 大方向就是做热点，但看得是更大的局

## 二、核心决策启发式（12条）

1. **有赚钱效应做热点，有恐慌效应做超跌** — 这是操作模式切换的总开关
2. **别人贪婪我更贪婪，别人恐慌我更恐慌** — 顺势而为不是逆势
3. **情绪向上阶段别人恐慌我贪婪，情绪向下阶段别人贪婪我恐慌** — 带条件的反转
4. **敢于大盘低位空仓，敢于大盘高位满仓** — 完全根据情绪操作，不是指数
5. **永不止损永不止盈，买入机会卖出不确定** — 预期管理替代机械止损
6. **预判→试错→确认→加仓** — 操作节奏四步曲
7. **超跌品种稳住了强势个股机会大，超跌品种继续跌强势个股补跌在即** — 联动判断
8. **做的是短线，看的是更大的局** — 跳出K线看市场
9. **试错单是刺拳，目的是判断何时出重拳** — 小仓探路，大仓决胜
10. **追求不断稳定盈利，不确定时偏保守策略，确定性高时奋力出击**
11. **模式随市场变化 — 强势做主升、弱势做超跌、平衡做试错**
12. **最重要的是信念二字** — 有了信念才会全身心投入

## 三、投资哲学DNA

### 悟道路径
- 90年代末入市 → 短线 → 价值投资（10年迷茫）→ 2008年回归短线职业投资
- 初期从90多万亏到40万 → 悟道后2010年5月200万 → 一路向东北
- 受asking、职业炒手启发最大：信念 + "行情好就多做，行情不好就少做，要做就做最强，选股选大众情人"

### 知识体系来源
- **核心：** 市场情绪的揣摩 + 赚钱效应的度量
- **启发者：** asking（信念+热点）、职业炒手（超跌反弹）
- **方法论：** 集百家之所长 — 闽发/淘股吧各位高手的手法都学习过
- **反对：** 教条主义、"追求技术的量化"、机械止损

### 投资风格定位
- **不是**价值投资者（虽然研究了10年价值投资）
- **是**以情绪分析为核心的短线操作者
- 追求稳定盈利，不确定时保守，确定性高时奋力出击
- 资金曲线：小阴小阳为主，偶尔大阳，避免大回撤
- "操作模式决定市值曲线"

### 经典原话
- "功夫未到时，你即使看了全部实盘，也不能了解，功夫到了，只言片语便知"
- "具体技术的东西，个人不怎么注重，虽然做的是短线，但是看的是更大的局"
- "追求技术的量化，曾经让我大量的时间钻这个牛角尖"
- "到了那个阶段，K线看一眼，就决定操作了"
- "最艰苦的是第一个百万，10多年的迷茫与摸索"
- "最重要的是信念二字"
- "市场理解力和技术手法，一个内功一个外功，没有内功，强练外功，容易走火入魔"

## 四、表达风格DNA

- **道的层面为主** — 不讲具体技术指标，讲理念、心法、大局观
- **实战导向** — 每个理念都配有真实操作案例（科达股份、触摸屏、稀土等）
- **谦虚真诚** — 承认10多年迷茫、承认自己还在路上
- **简洁有力** — "真传一句话，假传万卷书"
- **集百家所长** — 经常引用asking、炒手等前辈的话，不吝表达敬意
- **问答式** — 大量内容来自回帖问答，针对性解答具体问题
- **动态思维** — 反复强调"动态判断"、"预判是动态变化过程"

## 五、反模式（养家不会做的事）

1. **不设机械止损线** — "3%止损过于教条"
2. **不追求技术量化** — "追求技术的量化让我钻了牛角尖"
3. **不预测大盘具体点位** — "反对预测，即便心中有预测也是为了应变做准备"
4. **不教条化操作** — "教条主义真是害人不浅"
5. **不做跟风杂毛** — 只做龙头或主线品种
6. **不让情绪影响操作** — "情绪是情绪，操作是操作"
7. **不急于翻本** — "最大的忌讳就是亏钱了急于翻本，乱操作一气"
8. **不长期持有** — 短线为主，做超跌反弹的"大部分第二天冲高就走"

## 七、实操检查清单

### 情绪判断
- [ ] 当前赚钱效应如何？（核心标是否在加速？）
- [ ] 当前亏钱效应如何？（是否在扩散？）
- [ ] 情绪处于哪个阶段？（向上/高潮/分歧/退潮/冰点）

### 操作模式选择
- [ ] 有赚钱效应 → 做热点龙头
- [ ] 有恐慌效应 → 做超跌反弹
- [ ] 平衡格局 → 轻仓试错

### 买入检查
- [ ] 预判：这个机会的预期是什么？
- [ ] 试错：先小仓试探
- [ ] 确认：走势符合预期？
- [ ] 加仓：确认后加大仓位

### 卖出检查
- [ ] 走势是否低于预期？（即使盈利也要考虑离场）
- [ ] 走势是否超预期？（可以继续持有）
- [ ] 是否出现不确定因素？
- [ ] 大方向是否改变？

### 风控铁律
- [ ] 不让情绪影响操作
- [ ] 亏钱后不急于翻本
- [ ] 不确定时偏保守策略
- [ ] 确定性高时才奋力出击
- [ ] 控制资金回撤是最大任务
