# 作手新一 — 交易认知框架

## 一、核心哲学：行为学驱动的市场认知

作手新一的交易体系基于**行为学**建立。核心理念：

1. **对手盘思维**：每次买入都思考交易对手方是谁，目标客户是谁。游资的本质是在短期内快速完成大量筹码交换，完成财富重新分配。
2. **人气即流动性**：寻找市场活跃的人气股，参与游资机构多的标的。有上涨的必然逻辑推升，游资火上浇油，推波助澜，借风使力。
3. **逻辑内核是最强源动力**：逻辑>图形>题材。逻辑决定方向，图形确认时机。
4. **思路决定出路，格局决定结局**：从求道到得道的转变，核心是认知升级。

## 三、四大核心战法

### 1. 连板战法（主力战法，90%+占比）
- 从低位2连板逐步升级到中高位4连板、6连板，没有高度限制
- **进化路径**：慢连板→快连板→无高度限制
- 越高越追，模式接近"上海分公司模式"
- 代表着进化、专注、能力提高

### 2. 独创战法：排一字第三板
- **核心逻辑**：连续一字涨停的第3个板容易产生小分歧
- 前1-2板没有分歧，散户排不到
- 第3板：追涨者信心动摇 + 获利盘想卖 = 小幅放量
- 提前排单可能排到，是大量数据统计后的独创战法

### 3. 反包板
- 涨停→调整→再度涨停
- 最佳形态：**涨停→跌停→涨停**（阴阳并线），暴力美学
- 叠加：主流热点龙头 + 分时直线拉升
- 避免：慢悠悠型（爆发力差）、冲高回落中阳再涨停（潜伏盘多，轿子重）

### 4. 超跌首板（早期战法，后期<10%）
- 2017年上半年为主，后逐步抛弃
- 次新首板效果较好
- 从秒板（经常炸板）→升级到精选首板

## 四、37条核心心法（精选）

### 关于主线与龙头
1. **短线就要围着主线和龙头做** — 研究龙头、研究涨停，不断积累总结反思
2. **交易策略的核心是围绕主线做强势股** — 不同市场不同策略，但主线核心不变
3. **龙头打出空间打出赚钱效应才能由点带面** — 有"外挂"的股票先打出空间
4. **追涨必须选主线** — 不在主线的追涨是自找难受，封住了第二天也没接力
5. **不在主线的追涨都是自己找难受**

### 关于风控与仓位
6. **熊市比的不是快而是稳** — 确定性不光是概率，还有实效性和高盈亏比
7. **小资金控制回撤关键在控仓** — 行情好时拼命赚，以攻代守
8. **行情不好很少超过1/10仓位**
9. **满仓出击要有确定性**
10. **趋势向下时不参与小行情** — 对杂毛机会的屏蔽要做得很好

### 关于选股与买点
11. **盘中买点**：强势股超预期、涨停板打开、分时穿云箭、超预期高开、资金板块切换
12. **技术分析只看K线、均线、量能** — 人气逆转在标的选择时很考究这些
13. **选股看图形** — 图形是远观身段，题材行业是近观容颜，逻辑内核是了解内涵
14. **好的超短选手复盘要选股，盘中更要选股**
15. **标的符合模式就去做** — 涨停开了就开了，不影响模式执行

### 关于认知与悟道
16. **悟道=对市场有很好认知+能持续赚钱+能及时控制** — 虽有反复但始终可控
17. **核心竞争力是思维见识和执行力** — 自我成长围绕这两点进行
18. **利润来自对价值的发掘、对人性的纠错** — 不是你争我夺的收割
19. **理解投机价值**：你买了然后接你棒的人还会有念想
20. **股市最不缺的就是机会** — 再绝望时一根大阳线就改变三观

### 关于大资金行为
21. **大资金买股票更讲究时机和确定性** — 底下要不到筹码，封住要够筹码，还要顾及明天承接
22. **深刻理解仓位是理解大资金行为逻辑的开始** — 只有结构性大热点、牛市才能成就亿级资金
23. **捕捉大资金承载票** — 逻辑绝对主流、成交大，是小票打欢时大资金的火力输出点

### 关于心态与纪律
24. **短线乱打是回归赤贫的捷径** — 管不住手买杂毛，真机会来了没子弹
25. **正确的决定永远不嫌迟**
26. **不要去顶一字板** — 体力活交给通道专业户，散户买到的大概率是坑
27. **妖股逻辑**：人心思涨找不到逻辑，靠超跌妖股先打出赚钱效应，空间要拓开
28. **鉴别烂板价值关键是理解逻辑** — 了解公司质地，情绪博弈越来越需要结合内在价值

### 关于学习
29. **推荐书目**：《股票大作手回忆录》(必读)、《金融炼金术》、行为金融、《投资存亡战》、《富可敌国》、《激荡三十年》

## 五、交易体系演进

```
阶段1 (2012-2014): 以小做大，10万→200万
  - 临盘选择多，强势股超预期、分时穿云箭
  - 创业板牛市红利

阶段2 (2015): 快速暴发+惨痛教训
  - 4个月7倍，防守顶级
  - 期指做空失败，利润归零
  - 教训：不碰陌生领域

阶段3 (2016-2017H1): 恢复期，3000万→6000万
  - 首板为主，逐步升级

阶段4 (2017H2-2019): 专注连板，6000万→3亿+
  - 抛弃首板，连板占比90%+
  - 高度逐级抬高，没有限制
  - 从中低区域操盘→中高区域操盘
  - 更快、更专注、更高
```

## 七、与其他游资的区别

- **vs 温州帮/佛山派**：温州帮坐庄对手方完全是散户，不允许其他游资打扰；作手新一选择人气股，欢迎游资参与，通过快速筹码交换获利
- **vs 养家**：养家基于情绪周期，作手新一基于行为学；养家偏全局判断，作手新一偏个股逻辑
- **vs 赵老哥**：赵老哥早期首板为主，作手新一更早转向连板接力

## 八、适用场景（Agent使用指南）

当需要以下判断时参考本框架：
1. **连板接力决策**：高度、换手、分歧点的判断
2. **主线识别**：是否在主流线上，追涨逻辑是否成立
3. **对手盘分析**：大资金行为逻辑、筹码交换分析
4. **仓位控制**：不同市场环境下的仓位分配
5. **选股筛选**：图形+逻辑+题材的综合判断
6. **妖股/超跌反弹**：识别赚钱效应扩散的节点
