# 陶博士2006 交易认知框架

> 蒸馏自365篇博客（2006-2016年），约76万字。陶博士是中国最著名的欧奈尔CANSLIM体系实践者，以RPS（股价相对强度）为核心，结合行为金融学的反转/动量效应理论，构建了完整的A股中长线趋势投资系统。

## 一、核心心智模型（6个）

### 1. RPS股价相对强度模型

**底层逻辑：** 欧奈尔发现，每年股价表现最好的美国上市股票，在股价狂飙前的平均RPS为87。RPS介于1-99，过去一年涨幅排名前1%的股票RPS为99，前2%为98，以此类推。RPS是衡量一只股票相对于市场整体表现的最核心指标。

**陶博士实践法则：**
- **不买RPS<87的股票** — 这是铁律。RPS<80的金股候选直接排除
- **RPS稳定在95以上** — 动量效应出现的标志，意味着主升浪即将启动
- **RPS从低位快速上升到90以上** — 反转效应信号，新一批领涨股启动
- **RPS最高级别关注98以上** — 极强动量，历史上主升浪的典型起点

**实战案例：**
- 2002年10月，长安汽车RPS稳定在97以上 → 连续上涨8个月主升浪
- 2003年5月长安汽车冲顶后，扬子石化RPS稳定在98以上 → 六个月主升浪
- 2003年10月扬子石化最后冲刺时，贵州茅台/云南白药等超级长线牛股正式启动
- 2012年欧菲光RPS稳定在95以上 → 反转动量效应出现

**核心认知：**
- RPS是结果不是原因，高RPS背后必须有基本面强劲支持
- RPS与股价形态结合：杯柄形态+RPS>90 = 高胜率买点
- RPS适用周期：欧奈尔定义的"一年期"RPS，即250日涨幅排名

### 2. 反转/动量效应模型

**理论基础：** 不认可市场有效假说，认同行为金融学的反转效应和动量效应（Jegadeesh & Titman 1993）。

**反转效应：** 每年出现主升浪的股票多数情况下是不相同的——不同时期领涨股票不同。旧的热点退潮，新的热点崛起。

**动量效应：** 前一批股票主升浪之时，新一批股票也开始大涨，新一批股票的RPS超过90稳定在95以上。这批新股票经过N个月调整整理后，再现主升浪。市场如此循环往复。

**周期图示：**
```
旧热点主升浪 → 旧热点冲顶
                    ↓
新一批股票RPS上升到95+ → 新股票N个月调整 → 新股票主升浪
                                               ↓
                                    再新一批股票动量效应启动
```

**实战规则：**
- 在前一批主流热点冲顶时，开始关注RPS快速上升的新面孔
- 新面孔需要经过充分调整（N个月）才能启动主升浪
- "一花开放不是春，众花开放才安全" — 孤独上涨的板块风险大

### 3. 中期信号系统

**核心理念：** 陶博士有一套量化的中期买入信号系统，是决定仓位和操作节奏的关键。

**信号特征：**
- 上证指数站上50日线 + 一批股票放量确认底部 = 中期买入信号
- 信号持续时间从数月到一年以上不等
- 信号结束的标志：指数跌破关键均线、主流板块冲顶

**历史信号案例：**
- 2003年1月14日：大盘站上50日线，汽车板块集体放量确认底部
- 2008年11月14日：全球金融危机后的中期买入信号
- 2012年12月7日：陶博士公开发文《兄弟们！抄底啊！！》

**风险防范：**
- "风险防范永远是第一位的，哪怕错过机会也在所不惜"
- 信号出现后仍需警惕"上去做双头"的可能性
- 边走边看，设好止损位，等待信号的结束

### 4. CANSLIM中国化模型

**陶博士投资哲学形成路径：**
- 1995-2004年：尝试各种方法（巴菲特、林奇、格雷厄姆、索罗斯、江恩、艾略特），始终没有稳定盈利
- 2004年：反复阅读《笑傲股市》20+遍，初步形成以欧奈尔为基础的操作模式
- 2004年后：CANSLIM+实战经验+其他大师优点 = 陶博士系统

**CANSLIM七要素（陶博士中国化解读）：**

| 要素 | 欧奈尔原意 | 陶博士实践 |
|------|-----------|-----------|
| C 当季每股收益 | 上涨≥18%-20% | 关注季度业绩加速，超预期更重要 |
| A 年度收益增长 | 过去3年每年增长，25%-250% | 重视持续成长性，3年复合增长 |
| N 新高/新产品 | 股价创新高 | 重点关注"一年新高"，配合RPS |
| S 供给需求 | 流通盘适中 | A股中小盘优先，配合资金关注 |
| L 领涨/落后 | RPS>80 | 严格要求RPS>87，金股RPS>95 |
| I 机构认同 | 有基金持仓 | 关注北向资金、公募增持方向 |
| M 大盘方向 | 确认牛市 | 用中期信号系统判断大盘方向 |

**陶博士对欧奈尔的三大改进：**
1. **融入长期持有理念** — 欧奈尔偏短线交易，陶博士认为需要识别"每8只领导股中的那1只"可长期持有的
2. **增加定性分析权重** — 欧奈尔过重定量，陶博士增加"视野"和"定性判断"
3. **结合行为金融学** — 用反转/动量效应解释和预判市场轮动

### 5. 月线选股模型

**核心理念：** 用月线级别选股，捕捉主升浪。

**长线牛股技术特征（陶博士2013年总结）：**
1. 基本面反转向好，能支持数年上涨
2. 月线十根以上的底部平台形态
3. 最低点出现在前一年（如2012年1月见底）
4. 底部期间股价不创一年新低、也不创一年新高
5. 突破月创出一年新高
6. 日线向上穿越年线的时间在前一年第四季度

**金股选股框架：**
- 以欧奈尔RPS思想为主
- 适当结合西格尔《投资者的未来》行业思想
- 历史大牛股多集中在：医药、消费、能源相关
- "好货不便宜" — 不买低价股，牛市20元以上，熊市8-10元以上
- 一般选择在第四季度买入、第二年第二季度卖出

### 6. 估值与周期模型

**核心理念：** 估值是方向，趋势是确认，两者结合才入场。

**估值判断：**
- 牛市中PE不断上行：用历史PE区间判断上行空间
- 熟悉行业PE特征：银行5-15x，消费20-40x，医药30-60x
- PE比较：与成熟市场（美/英/日）对比判断泡沫程度
- 解决泡沫的唯一途径是放大泡沫让其自行破灭

**周期判断：**
- 开放式基金正反馈循环：牛市→净值涨→申购增→买股→再涨
- 负反馈迟早要来，时刻提高警惕
- 泡沫极限时，基金重仓股必然是下跌重灾区
- 所有货币/财政政策在泡沫面前都是苍白无力的——直到资金衰竭

## 二、核心决策启发式（12条）

1. **RPS<87的股票不看** — 一年涨幅排名后13%的股票直接排除
2. **RPS从低位站上95 = 关注，稳定95以上 = 重点跟踪，到98 = 准备入场**
3. **旧热点冲顶时，找RPS正在上升的新面孔** — 这是反转/动量交替的核心
4. **中期买入信号 = 大盘站上50日线 + 一批股票放量确认底部**
5. **月线底部平台（10根以上）+ 基本面反转 + 创一年新高 = 长线牛股启动**
6. **基本面是基础，技术面是确认，RPS是桥梁**
7. **不买低价股：牛市20元以上，熊市8-10元以上**
8. **第四季度建仓，第二年第二季度卖出是中期操作节奏**
9. **风险防范永远第一，错过机会也在所不惜**
10. **一花开放不是春，众花开放才安全 — 孤独上涨的板块风险大**
11. **"好货不便宜" — 最优秀的股票通常价格较高**
12. **如履薄冰 — 交易者最大敌人是资金回撤，坚持控制回撤**

## 七、实操检查清单

### 选股流程
- [ ] RPS是否≥87？（一票否决）
- [ ] 基本面是否反转向好？（季度/年度业绩增长）
- [ ] 股价是否在20元以上（牛市）或8-10元以上（熊市）？
- [ ] 月线形态是否健康？（底部平台/杯柄/基底）
- [ ] 是否属于强势行业？（医药/消费/新能源等）
- [ ] 是否有机构资金关注？

### 买入流程
- [ ] 中期信号是否出现？（大盘站上50日线）
- [ ] 是否有一批股票同步放量确认底部？（众花开放）
- [ ] 是否在第四季度附近？（最佳建仓窗口）
- [ ] 止损位是否设定？

### 持有/卖出流程
- [ ] RPS是否仍然≥90？
- [ ] 是否到了第二季度？（中期卖出窗口）
- [ ] 是否主流热点开始冲顶？
- [ ] 资金回撤是否在可控范围？

### 风控铁律
- [ ] "如履薄冰" — 每笔交易都要考虑最坏情况
- [ ] 错过机会比亏损好
- [ ] "风险防范永远是第一位的"
