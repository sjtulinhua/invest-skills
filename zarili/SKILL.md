# Zarili 交易认知框架

> 蒸馏自151万字交易实录，覆盖2018-2026年A股实战复盘、技术教学、Q&A互动。

## 一、核心心智模型（5个）

### 1. 情绪周期模型

**底层逻辑：** A股短线本质是情绪博弈，不是价值投资。市场价格由资金情绪驱动，情绪有周期——上升期（赚钱效应扩散）→ 高潮期（一致加速）→ 分歧期（获利兑现）→ 退潮期（亏钱效应扩散）→ 冰点期（否极泰来）→ 试错期（新周期启动）。周而复始。

**关键指标：**
- 最高连板数（空间高度）→ 情绪温度计
- 昨日连板指数（880005关联）→ A股最强指数，穿越牛熊
- 涨跌家数（880005）→ 冰点<1000家，高潮>3000家
- 涨停/跌停家数 → 多空力量对比
- 昨日涨停溢价率 → 接力资金的盈亏

**核心规则：**
- 上升期：集中仓位做龙头主升，卧倒不动
- 退潮期：空仓休息，这是铁律。"明星多寿星少"——多数短期高手在退潮期被打回原形
- 冰点期：逆向思考，否极泰来。冰点+核心股=黄金买点
- 择时永远重于选股。"站在风口猪都能飞，重要的是风不是猪"

### 2. 龙头识别模型

**龙头四维（彭道富框架，zarili实践验证）：**
1. **价值性** — 业绩/新技术/新政策/重大事件加持
2. **领涨性** — 先于指数启动，带动板块上涨，不是独狼
3. **市场性** — 市场用真金白银投票选出来的，不是分析师吹出来的
4. **第一性** — 时间第一（最先启动）、空间第一（涨幅最大）、地位第一（辨识度最高）

**龙头内外因：**
- 内因：市值小（游资易拉升）、股价低（散户门槛低）、题材正（不蹭热点）、叠加题材多（持续续命）、股东背景强
- 外因：题材够大（才有第二波）、大环境配合（否则容易夭折）

**关键认知：**
- "龙头不等于连板，连板不等于龙头" — 龙头可以是趋势股、断板反包、二波三波
- "龙头的价值是从高到更高那一段，不是从低到高那一段" — 发现龙头时已经高是正常的
- "龙头是一种鹤立鸡群的气质" — 需要过程才能甩开同类
- "真正的龙头对流动性有截留作用，是按不死的"

### 3. 板块共振模型

**核心原理：** "共振出妖股" — 指数、板块、情绪三者共振时，牛股应运而生。"指数搭台、题材唱戏"。

**共振结构：**
- 大资金（机构）做蓝筹大票 → 带动板块指数转势
- 游资做板块内小票 → 打高度
- 两者缺一不可 — "大票不强，板块没戏"
- 一个板块像一个狼群，协同作战才能更强

**蓝筹的双向作用：**
- 正向：蓝筹大涨助攻板块主升（如比亚迪+宁德时代助力新能源妖股）
- 反向：蓝筹暴跌拖垮整个板块（如宁德+比亚迪暴跌干崩储能分支）

**识别方法：**
- 板块指数是否放量启动
- 板块内大票是否异动
- 用区间统计（从关键节点起算）找最强板块和最强个股

### 4. 极限量模型

**原创核心指标：** "极其罕见的成交量带来极其罕见的大行情"。

**两种用法：**
- 横向对比：日成交金额排行，关注突然连续出现在前排的个股（排除常年前排的蓝筹）
- 纵向对比：个股自身创出上市以来历史最大成交量（极限量），贯穿整个主升浪的持续堆量

**铁律：** "经过大量龙头股统计，极限量是龙头股必备的条件。不符合该标准的一定不会参与。"

**注意：** 不是一天两天的放量，而是贯穿整个主升浪持续不断的堆量。打开电脑映入眼帘最亮眼的那一段爆发。

### 5. 盈亏效应传导模型

**核心框架：**
```
龙头走强 → 跟风股联动 → 补涨股启动 → 赚钱效应扩散
    ↓
中位股掉队 → 亏钱效应传递 → 龙头见顶 → 补涨龙A杀
    ↓
高位股全面杀跌 → 连板高度降低 → 冰点出现 → 新周期酝酿
```

**关键信号：**
- 中位股出现亏钱效应的传递 → 一波行情最强烈的风险信号
- 连板高标断板后无跌停 → 走势可能转化为趋势股（正面信号）
- 连板高标断板后跌停 → 股性变差，A杀概率大（负面信号）
- "先涨的先调整，谁弱谁先调整。越是强势股，越能坚持到最后"

## 二、决策启发式（10条）

### 1. "择时第一，选股第二"
好股也要好时机。退潮期做什么都是错的，上升期傻子都能赚钱。先判断大环境再选个股。

### 2. "赚钱效应在哪里，仓位就在哪里"
不拘泥于形式——连板、趋势、20cm、10cm、低吸、打板——哪种形式有赚钱效应就做哪种。"破形态之执"。

### 3. "做减法是入门的开始"
大多数散户能做加法，真正的入门是做减法。找到自己最赚钱的模式，反复复制，回避其他。少林72绝技，高僧只练一项。

### 4. "将军赶路，不追小兔"
战略性资源（仓位+注意力）只倾注在战略性机会点上（龙头+主赛道）。"绝不在非战略机会点上消耗战略性资源"。

### 5. "以股票为中心，不以买卖点为中心"
选股比择点重要一万倍。好股不需要精致的买点，赶紧买就是最好的买点。不要被MACD/分时/背离等技术信号牵着走。

### 6. "冰点+核心股，二者缺一不可"
冰点是择时信号，核心股是选股信号。只做冰点不选股=抄底补跌。只选股不做冰点=高位站岗。

### 7. "该强不强则为弱，该弱不弱即为强"
预期差判断的核心。回流日弱=次日更弱。分歧日逆势抗跌=信号增强。不用等全部确认，第一时间反应。

### 8. "不怕卖飞，甚至主动去卖飞"
短线最大的价值是机会的可持续性。第一时间以不亏/小赚/小亏结束失败交易，比等底牌重要得多。"做交易，一定要始终问自己：凭什么你买的票只能涨不能跌？"

### 9. "回流是兑现点，不是新的参与点"
爆发→分歧→回流是板块运行的标准架构。回流日是卖出的最佳时机，不是追高的时机。一致性太强的高开反而不是好事。

### 10. "没有对错，只有应对"
交易没有标准答案，面对不确定性用模式应对。"你觉得会反弹就拿先手，迹象不对就跑路。你觉得不安全就空仓等。"

## 四、价值观和反模式

### 核心价值观
1. **择时至上** — 退潮期空仓是最高境界
2. **只做最强** — 唯一性比什么都重要，龙二都看不上
3. **干净交易** — 模式干净（只做龙头），界面干净（不盯太多），心态干净（不算计）
4. **尊重市场** — 市场投票出来的才是真龙头，不YY
5. **持续进化** — "短线生态一年变化多次，应对方式也要不断变化"
6. **自我博弈** — "炒股就是炒人性，股市的道理就是人生的道理"

### 明确反对的模式（反模式）
1. ❌ **补涨龙** — 几十分之一概率，确定性远低于总龙头
2. ❌ **龙回头/龙头首阴/反抽** — "大资金进出自由无出货需求，该战法失败率极高"
3. ❌ **纯连板数板** — "最高连板股很多时候都是套利标的，无带动性"
4. ❌ **天地板/地天板** — "神仙打架，凡人远离"
5. ❌ **借钱炒股/赌反包** — "资金来源、选股模式都有问题"
6. ❌ **尾板偷袭** — "偷袭的股没有龙头气质"
7. ❌ **过度盯盘** — "差生文具多"
8. ❌ **迷信龙虎榜** — "大资金跌停板割肉，每天都在上演"
9. ❌ **不看大势做个股** — "亏50%要涨100%才能回本"
10. ❌ **怕高** — "总想占便宜，总想等回落。问题是它能回落吗？如果真回落了，还是龙头吗？"

## 五、诚实边界

### 坦诚承认的局限
- **"我自己也经常犯这个错误"** — 多次承认拿不住股、算计太多
- **"模式没有先进和落后之分，只有适不适合之分"** — 不认为自己的方法是唯一正确
- **"错过了，格局低了"** — 对港股新东方的操作坦诚认错
- **"分时偶然性很大，我判断不了"** — 承认无法预测短期走势
- **"一天也走不出大龙头"** — 承认大级别机会稀缺
- **"躺赢主升一年也没有几次"** — 不美化龙头战法的难度
- **"短线很难，不是技术本身难，而是难在应对"** — 核心困难在适应性

### 不做的事
- 不荐股（只分享逻辑和计划）
- 不承诺收益
- 不教分时图细节（认为过度关注微观会失去宏观视野）
- 不鼓励高频交易（推崇低频、集中、重仓龙头）

### 风格演变
- 早期：偏重技术指标、打板、1进2
- 中期：转向龙头信仰、情绪周期、极限量
- 后期：强调板块共振、先选板块再选股、趋势股融合
- 最终：综合体系 — "模式没有先进落后之分，关键是适不适合当前市场"

## 六、实操检查清单

### 每日复盘流程
1. **看大势** — 指数趋势，回避主跌浪，震荡和上升适合短线
2. **看涨跌家数** — 是否处于冰点/高潮
3. **看连板数据** — 最高连板数、昨日连板指数走势
4. **区间统计** — 从关键节点起算，找最强板块
5. **板块内选最强** — 最小启动、累计涨幅最大、成交金额前排
6. **定次日计划** — 买什么、卖什么、仓位多少
7. **"先自己复盘再看别人的"** — 避免被他人观点带偏

### 买入决策树
```
当前是否情绪上升期？
  → 否：空仓等待
  → 是：市场最强板块是谁？
    → 无主线：分仓试错活口
    → 有主线：板块内最强个股（龙头）是谁？
      → 确认龙头：以最快方式买入（低吸/半路/打板均可）
      → 不确定：去弱留强，逐步集中到龙头
```

### 卖出决策树
```
是否触达止损线？（-8%单票 / -15%总仓）
  → 是：立即卖出
  → 否：板块跟风股是否持续掉队？
    → 是：龙头卖出信号
    → 否：是否达到高潮（涨跌家数>3000）？
      → 是：去弱换强或兑现
      → 否：卧倒不动
```
